# Keyword levels — Слово-ключ

Публичный контент игры: https://github.com/ThemeCross/Keyword-levels.
GitHub Pages публикует корень ветки main. Здесь только JSON заданий и индексы;
исходники iOS-приложения и служебные настройки находятся отдельно.

## Загрузка по заданиям

Новый клиент использует
https://themecross.github.io/Keyword-levels/catalog-window-ru.json.
Это schemaVersion 2, language ru, generation 2.

- `main`: ID, порядок, редакция, путь и SHA-256 каждой отдельной сетки.
- `events`: название/описание, версия, неизменяемый `startsOn`, необязательное
  публичное начало `availableFrom` и список day/path/sha256 отдельных заданий.
- `main/*.json`: одна основная сетка. `event-tasks/*.json`: одно задание события
  с сеткой и определением ключевого слова. В индексе нет ответов и сеток.

Клиент скачивает только выбранное задание и три следующих. Уже встроенные,
скачанные и начатые задания используются повторно. Общее количество заданий и
расписание известны по индексу без загрузки всех сеток. Списки и карточки показывают
по десять заданий; следующие страницы скрыты до открытия предыдущей.

Принятые ID, порядок, редакции, nominal `startsOn` и hash-файлы неизменяемы.
Новые основные уровни добавляются в хвост; новую тему публикуйте с новым ID.
Изменённый индекс получает новое поколение. Сначала размещайте объекты, затем
индекс, либо всю поставку одним commit. Дождитесь успешной публикации GitHub Pages.
Ошибка сети/хеша не удаляет сохранения; уже проверенный локальный префикс остаётся.

Текущая поставка: прежние 200 основных уровней и 30 заданий «ИИ и технологии».
Публичное окно первого входа в тему — 25.11–24.12.2026 UTC. Номинальные даты
контента и ID прежние; начатая тема продолжается после окна.
Новые слова, тестовые production-уровни и новые платные продукты не добавлялись.

## Совместимость

`catalog-ru.json` (schemaVersion 1, generation 1) и прежние `events/*.json`
сохранены без изменений для старых клиентов, загружающих полные пакеты.
Новый клиент не скачивает эти полные тематические пакеты. Его старый локальный
кэш читается и переносится на загрузку по отдельным заданиям.

Экспортёр находится в проекте приложения, `Tools/export-cloud-catalog.py`:

```sh
python3 Tools/export-cloud-catalog.py --output '../Keyword-levels' --generation 2 --window-only
```

`--window-only` сохраняет legacy-индекс и полные старые пакеты. Без флага экспортёр
также создаёт совместимый индекс schema 1. Входные файлы всегда содержат полный
принятый контент с неизменённым префиксом. Экспорт не заменяет редакторскую приёмку.

Сайт ThemeCross.github.io содержит страницы игры и политики. Прежняя копия
каталога `/keyword/levels` удалена; этот репозиторий — единственный источник.
