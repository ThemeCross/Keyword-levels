# Keyword levels — Слово-ключ

Отдельный публичный репозиторий: https://github.com/ThemeCross/Keyword-levels.
Источник приложения: https://themecross.github.io/Keyword-levels/catalog-ru.json.
GitHub Pages публикует корень ветки main, как в ThemeCross/levels для Сканворда.
Здесь только JSON головоломок и manifest; код приложения находится отдельно.

`catalog-ru.json`: schemaVersion 1, language ru, generation 1; main — записи
kind/id/order/revision/path/sha256, events — kind/id/version/path/sha256.
Файл main содержит один Puzzle, файл events — один тематический Event.
Имена файлов включают SHA-256; опубликованные объекты не перезаписываются.
Следующее поколение добавляет новые ID в хвост, сохраняя прежние сетки и порядок.

Первоначальная поставка: 200 принятых основных уровней и тема «ИИ и технологии».
Новых слов или тестовых production-уровней не добавлено.
Сначала публикуются файлы, затем manifest. Клиент принимает только целую
совместимую поставку; ошибки сети/формата не удаляют локальный прогресс.

Каталог содержит данные, не исполняемый код. Секретов, конфигурации SDK,
токенов доступа или данных игроков здесь нет.


## Обновление контента

Добавляйте только принятые уровни с новыми ID в конец последовательности.
Сохраняйте старые сетки, порядок и hash-файлы. Для изменения полного manifest
увеличивайте generation; версия отдельной сетки не является поколением каталога.
Сначала размещайте объекты, затем manifest, либо публикуйте всю поставку одним
commit. Дождитесь успешной публикации GitHub Pages для этого commit.

Экспортёр находится в приватном проекте Keyword, Tools/export-cloud-catalog.py:

```sh
python3 Tools/export-cloud-catalog.py --output '../Keyword-levels' --generation 2 --main /path/to/approved-main.json --events /path/to/approved-events.json
```

Это пример для следующего поколения, а не команда проверки текущей поставки.
Входные файлы содержат полный принятый набор, включая неизменённый префикс.
Проверки качества контента и запуск приложения выполняются отдельно с разрешения
владельца. Экспортёр сериализует JSON, но не заменяет редакторскую приёмку.

Код iOS-приложения остаётся в приватном ThemeCross/Keyword. Репозиторий сайта
ThemeCross.github.io содержит страницы игры и политики. По прежнему адресу
/keyword/levels оставлена замороженная совместимая копия generation 1 для
старых сборок; новые поколения публикуются только в этом репозитории.
